# Design references

DESIGN.md files describing the design systems of well-known products, one folder per product. Copied from [voltagent/awesome-design-md](https://github.com/voltagent/awesome-design-md) at commit `c7c1bada4eda972236d124e06ee58df129a9266b` (13 Oct 2026), under its MIT licence (`LICENSE`). The upstream README is kept as `UPSTREAM-README.md`.

These are references for choosing a visual direction for the app. None is adopted: the app uses neutral design tokens until a direction is supplied (see `docs/PRD.md`, "Design direction").
